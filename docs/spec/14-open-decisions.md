## 要確認の優先度

実装開始前に決めたいもの:

1. **D24**: メモリ履歴をモジュールにするか、コアに持たせるか。コアの責務と `ctx.history` の形に直結する。
2. **D5**: ロール一覧と排他性。manifest と起動検査に直結する。
3. **D18**: イベント payload。UI とテストの契約になる。
4. **D9 / D13**: 非同期ツールの完了とタイムアウトの契約。
5. **D16 / D6**: config と承認の保存形式。起動フローに直結する。

## 補完の原則

- 原文に書かれた語彙・イベント名・権限名は変えない。
- 原文が「未決定」としたものは、勝手に確定せず TBD のまま残す。
- 実装上都合で決めたものは、この表に追記してから実装する。
