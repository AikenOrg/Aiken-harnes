## 同梱モジュール

- `src/modules/provider-mock` — `mock/echo` を返すプロバイダー
- `src/modules/tools-read` — `read` 同期ツール
- `src/modules/shell` — `shell` 非同期ツール（whitelist / full）
- `src/modules/provider-anthropic` — Anthropic Messages API プロバイダー
- `src/modules/provider-opencode-go` — OpenCode Go プロバイダー

## 動かす

```sh
bun install
bun run check
printf 'hello\n' | bun run src/index.ts --config config/dev.config.json --approve-all

# 実プロバイダー
ANTHROPIC_API_KEY=... bun run src/index.ts \
  --config config/anthropic.config.json --approve-all

# OpenCode Go
OPENCODE_API_KEY=... bun run src/index.ts \
  --config config/opencode-go.config.json --approve-all
```

`--events` を付けると全イベントを表示する。Anthropic の raw ログは `logRaw: true` と `log.level: "debug"` で出す。承認 UI は M4 のため、現状は `--approve-all` で明示的に全権限を許可する。

## 既知の制限

- `harness.send` はセッション単位で直列化する。複数セッションは並行可能。
- `HistoryManager` の読み取りスコープはモジュール権限で検査するが、セッション子孫の制限は M2 で詰める。
- `tool.before` の引数書き換えは再検証する。shell のホワイトリストは実装済み。承認 UI は M4。
- result-store はメモリ実装。再起動復元と TTL は SQLite 実装時。
- CLI は `--approve-all` なしだとモジュールを承認できないため起動しない。
- Anthropic / OpenCode Go 実装は SSE / 変換を fake fetch でテスト済み。OpenCode Go の実 API スモークテストは、保存済み credential が `Invalid credential` で拒否されたため未完了。Console で新しい Personal API key を作成し、`OPENCODE_API_KEY` に設定する必要がある。
- shell のホワイトリストは先頭トークンの basename 比較。シェル構文の完全な解析はしない（既知の受容リスク）。
- プロセスツリーの kill は Linux のプロセスグループと Windows の `taskkill /T /F`。Windows 実機は未検証。
