# ADR 0003: 仕様の優先順位

- 日付: 2026-11-07
- 状態: 採用

## 文脈

ユーザー提示の原文スペックと、実装のために分解した仕様書の間に食い違いが生まれる可能性がある。

## 決定

優先順位を次の通りとする。

1. `docs/requirements/original-spec.md` (原文。編集禁止)
2. `docs/spec/` の各仕様書
3. コードとテスト

- 原文に無い補完は `docs/spec/14-open-decisions.md` に記録する。
- 派生仕様が原文と矛盾する場合、原文を正とし、派生仕様を修正する。
- コードが仕様と矛盾する場合、仕様を更新するかコードを直す。どちらかを必ず同じ変更で行う。

## 影響

- 仕様変更のレビューは、原文との差分と 14-open-decisions の更新を確認する。
- イベント名・権限名・型名は原文の表記を維持する。
